# 1.1.2 — 论文头部改版与后台页面预加载

1.1.1 仅记录了阅读器头部的设计方案，本版补齐实现。

- 阅读状态改为与批注、关联一致的轻量操作，默认透明、无可见外框；保留文字和低饱和色点。
- 状态菜单显示当前勾选，支持方向键、Enter、Escape 与操作后焦点返回。
- 标题最多显示两行；操作组空间不足时换到下一行，不再靠压缩标题容纳全部按钮。
- 作者、来源、年份和页数单独分组；标签可展开查看全部内容，较窄界面收为数量入口。
- 状态保存期间保留原状态并显示轻量进度；服务器确认后才更新。保存失败时保留原状态，显示原有错误提示。
- PDF 初始在后台准备前 10 页，读到第 8 页时扩展下一批；后续每批 10 页，保留最多两个批次。快跳或回看时调整准备范围。
- 当前页画布与文本层优先；后台一次只处理一页，滚动和选字时暂停。低清预览缓存最多 20 页，每页最多 262144 像素；这不包含 pdf.js 自身资源与当前可见画布。
- 可用渲染 worker 时提前生成低清预览；回退到主线程渲染的环境只准备页面解析数据，减少后台光栅绘制对交互的干扰。预加载失败不会阻塞正常阅读。

验证命令：

```sh
npm run typecheck
npm run build
npm run test:ui-state
npm run test:regression
npm run smoke
npm run test:pdf-preload
npm run test:pdf-links
npm run test:pdf-highlights
```

类型检查、构建及 10 套共 530 项程序检查通过。40 页合成 PDF 已用真实 pdf.js 验证页数、逐页文字与第 12 页的固有旋转。

隔离合成库的实机检查已覆盖四个状态、键盘选择、重载持久化、写入失败保持原状态与恢复后保存、标签浮层、浅深主题和 150% 缩放。外观设置已恢复，缩放回到 100%。失败测试只临时调整合成目录权限，随后恢复，并核对了文件哈希。

40 页合成 PDF 在第 8、11、18、30 页及回到第 8 页的观察中未见明显白屏或卡顿，第 12 页固有横向排布、缩放和一行拖选正常。界面只读 AX 显示附近约五页，未读取内部预取属性；具体批次由程序检查支持。本轮没有测量帧率、延迟或整个进程内存，不能据此保证所有硬件与复杂 PDF 都有相同表现。模型调用为零。

本地由用户在插件管理器关闭再开启后，只读核对界面与后台均为 1.1.2，原来选中的 Index-Translate 论文保持。没有编辑真实论文或 native/global 配置；真实库总数在该次界面中不可见，因此不宣称核对了数量。

# v0.4.6

AI 助读按用户选择的第一张方案改版，卡片保存弹窗也采用同一阅读风格。

- 顶部保留当前对话、新建和更多操作；重命名、删除、回答字号及完整会话入口放入更多菜单。复制和单一保存菜单对应每条回答，保存目的地仍为论文笔记或卡片。
- 回答使用 16px 基准字号、1.85 行高和清晰的标题、段落间距。回答批注收为可展开的一行；工具及推理过程可展开查看。引用页码保留在回答尾部，点击核对原页。当前引用协议没有段落级定位，不推测某个页码支持了哪一段。
- 输入框统一容纳问题、任务和 PDF 原页图片。任务先选择，点击发送后执行；也可补充具体问题。任务沿用既有准备提示词接口，指定的页面图片通过既有多模态消息协议一并发送。
- 图片附件显示明确的页码，可编辑或逐个移除。最多附上 3 个不同页面，拒绝非法页码及超出论文范围的页面。附件固定为添加时的页码，不随阅读器翻页改变。
- 草稿文字、任务和附件按论文及对话区分。请求被接收后清除本次草稿；失败保留。图片准备完成后检查当前会话再发送；晚到的接收结果不会清空其他对话的新草稿。现有文字草稿存储格式继续兼容。
- 桌面侧栏保留拖动宽度；小于 720px 时采用全高浮层，避免回答区被固定高度的 PDF 区域压缩。关闭后回到阅读器。
- “保存为卡片”改为纸面式弹窗：突出标题与正文，已有正文默认显示 Markdown 预览，可切换编辑；来源页码、标签和上下文采用次要层级。保存与取消固定在底部。“根据对话生成”放在展开的上下文区域，明确说明会替换当前标题和正文。关闭再打开时，旧生成请求的结果不会覆盖新卡片。

验证命令：`npm run typecheck`、`npm run build`、`npm run test:ai-composer`、`npm run test:regression`、`npm run test:ui-state`。输入框专项 23 项、既有回归 67 项、UI 状态 14 项通过。真实界面验收包含配置模型的原页图片问答，与 mock 的协议检查分开记录。

真实界面验收 6/6 通过，12 份所需证据齐全。实际使用 deepseek-official / deepseek-flash 完成原页图片问答，验证对话管理、草稿和附件恢复、回答复制、引用页面与回答批注；隔离库实际保存新版弹窗的卡片，并确认取消编辑不写入。追加笔记仅检查菜单入口，未将其视为本轮实际写入验证。600px 下回答区过矮的问题已修复并复验；1000px 和宽屏布局通过。原生插件已通过 UI 刷新至 0.4.6，未在真实论文中保存测试内容。验收服务及专用标签已清理。

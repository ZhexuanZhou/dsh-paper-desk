# v0.5.2

- 卡片阅读页与编辑预览统一排版：正文继承界面无衬线字体，16px/1.85行高，正文与卡片标题同左边线；取消阅读页额外的70ch居中窄栏。
- 卡片正文标题统一为22/19/17px层级，去掉仅阅读页存在的大间距、绿色章节标题和分割线。表格统一14px，长表格在自身范围滚动。笔记页面的既有排版不变。
- 通过Marked词法结果识别正文第一个有效块，仅当其为与卡片标题同名的heading或独立paragraph时，在阅读/预览中省略。不同标题、含额外说明的段落、代码、链接、引用和后续同名标题均保留。
- 这只是展示处理，不改写卡片正文或历史版本；源码编辑、复制与插入笔记继续使用原始内容。

验证命令：

```sh
npm run typecheck
npm run build
npm run test:markdown
```

类型检查与构建通过，实际构建 bundle 和源码渲染共85项检查通过（新增标题展示14类样例各核对期望值及构建一致性，既有Markdown/公式57项）。

隔离演示库的卡片阅读与编辑预览两项界面验收通过，包含宽屏和600px窄屏、标题去重、列表与表格排版。源码编辑保留原正文；复制保留既有来源说明及完整原正文，卡片文件未被改写。本轮未调用模型或写入真实用户卡片。

本地客户端已显示0.5.2。后台版本信息仍缓存为0.5.0；未独立确认原生应用中的卡片布局，卡片排版以隔离界面验收为准。

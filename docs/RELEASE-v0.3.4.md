# PaperDesk v0.3.4 — 对话跟着论文走

## 新增：论文内多对话管理

- 每篇论文可以有多条对话，存在 `papers/<id>/chats.json`，跟随论文库云盘同步。
- AI 抽屉顶部新增会话栏：切换、`+` 新建、重命名、删除（带确认）；标题默认取第一条提问。
- 每轮问答结束后自动把 user/assistant 文本保存进对话记录；引用页码、生成卡片、保存到笔记照旧。

## 侧栏 session 不再是唯一副本

- 左侧栏的 DSH session 只是执行会话；**从 sidebar 删除/归档 session 后，插件里的对话记录还在**。
- 打开一条 session 已失效的对话时，抽屉会显示插件保存的历史记录；继续提问会创建新 session，并把这些历史作为上下文带过去。
- “新会话”按钮仍可用于丢弃当前执行会话、重新开始（对话历史保留）。

## 安装

```sh
dsh plugin --profile web add @zhe_xuan/dsh-paper-desk
```

## 验证

- 新建对话 → 提问 → 记录自动保存（标题自动生成）
- 新建第二条 → 下拉切换 → 回到第一条
- 删除对话后其余对话保留
- 清空本地 DSH thread 缓存（模拟 sidebar 会话被删）→ 重开论文 → 历史记录显示在抽屉；继续提问正常回复
- 中文/英文文案、tsc、构建通过

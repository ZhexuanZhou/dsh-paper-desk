# v0.3.31

- AI 回答统一「保存为卡片」，移除「保存到笔记」入口；卡片是原子结论
- 卡片支持多轮对话上下文：保存时默认带当前回答与前文，编辑器里可勾选更多轮次
- 卡片编辑器新增「根据对话生成」：由 Host 模型把选中的多轮对话整理成标题/正文/标签/页码
- 已有卡片可在编辑器中追加对话上下文
- 笔记页卡片区新增「生成总结」：根据全部卡片由 Host 模型生成总结并追加到 notes.md
- 笔记页支持勾选多张卡片合并，合并后保留上下文/标签/页码
- 卡片 context 存入 cards.json，向后兼容旧卡片

安装：`dsh plugin --profile web add @zhe_xuan/dsh-paper-desk`

# v0.4.8

- 去掉 AI 助读的任务下拉框、空态固定任务按钮，以及回答下方的保存菜单。直接用自然语言请求总结、记笔记、保存卡片或整理卡片。
- 新增 `paper_card_create`、`paper_card_update` 工具。读取卡片的模型可见结果包含 ID、版本、正文、标签和来源页码；更新校验 `expectedUpdatedAt`，并行写入按论文串行处理。
- 普通总结和问答只读。明确要求记录才使用写入工具；默认整理当前论文全部卡片，保留原卡片并新增综合卡片。失败或部分完成须如实反馈。
- 连续的推理和工具事件合并为一个默认折叠的过程摘要，展开后保留原始顺序；不跨提问、回答或错误边界合并。长问题默认紧凑展示，可展开阅读全文。
- 回答复制直接使用原始 Markdown，保留 TeX 公式、代码和列表，不从渲染后的 DOM 提取文字。
- 选区批注改成面板内引用编辑区，支持查看长引用、保存批注、直接提问、取消及 Esc；保留选区高亮，不覆盖正文。
- Agent 执行结束后刷新笔记和卡片；笔记编辑器保留未保存的草稿。旧任务草稿忽略任务字段，保留文字和明确的图片页码。

npm run test:ai-composer
node scripts/test-ai-display.mjs

自动化检查覆盖真实工具调用和落盘、综合卡片保留原件、过期更新拒绝、非法输入、并发创建，以及旧草稿兼容。类型检查和构建通过，自动化检查共 188 项通过。独立合成演示库中，4 次真实模型请求验证了普通总结只读、记录笔记、创建卡片和全卡片综合整理；笔记与卡片自动刷新，综合整理保留原卡片的业务字段和时间戳。界面验收 6/6 通过，复制内容与原始 Markdown 逐字一致并保留 TeX；600px 宽下选区操作可达，第一次 Esc 关闭选区，第二次关闭 AI 面板。批注保存是当前浏览器的本地存储，不等同于写入论文笔记。示例只使用合成演示库，没有改动真实论文。自动化工具检查与真实模型记录分别保留。

# v0.4.1

- 专题页分为新建和已保存两种状态。新建时依次填写问题、选择论文、保存；笔记折叠为可选内容，讨论栏在保存后显示。已保存专题继续使用原有资料和会话。
- 文献发现增加检索初始引导、示例关键词和订阅空状态。输入关键词后单独说明订阅用途，不依赖 arXiv 检索成功即可保存检索词；高级检索语法按需展开。
- 专题与订阅加载失败时显示独立恢复页，不再将不可用表单与原始 `not-found` 混在一起。404 提示重新启用插件后台；重新加载只重试资料读取，不发起空检索。
- 每条 AI 回答只有一个“保存”菜单，可选择追加到论文笔记或打开卡片编辑器。两种保存行为与既有数据格式保持一致，实时回答与历史回答共用该入口。
- 延续低饱和灰绿与暖白配色。修正回答操作区的按钮字号与主按钮文字颜色覆盖。

本次不改变 Host API、论文、专题、笔记或卡片的数据格式。自动化检查为 `npm run typecheck`、`npm run build`、`npm run test:regression` 和 `npm run smoke`；真实产品的局部验收记录于 `.acceptances/standalone-paperdesk-redesign/` 的后续轮次。

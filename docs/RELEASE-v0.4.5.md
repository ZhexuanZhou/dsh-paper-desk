# v0.4.5

- 修正 PDF 文字层的宽度校准：保留原文的字宽，仅合并同字体、同字号、同一行且相接的文字片段。不同栏、公式字体和行尾保持分开。文字层与 pdf.js 测量画布使用相同的语言设置，避免中文宿主环境改变通用字体的宽度。
- 从选区中的文字节点读取矩形，不再把父元素边框一起保存；去掉重复矩形，并裁切到当前页面范围。跨页选区和超过数量限制的选区不会被部分保存。
- 每条高亮整体应用一次透明度。同一条高亮内的矩形即使相交，也不会因重复叠色而局部变深。浅色和深色阅读模式保持各自的混色方式。
- 旧高亮及划线可依据原文重新定位显示。只接受空白归一后唯一匹配的完整引文；找不到、重复出现或已截断的引文保留原坐标，不猜测位置。此过程不修改 `annotations.json`，也不恢复已删除的批注。

验证命令：`npm run typecheck`、`npm run build`、`npm run test:pdf-highlights -- <原始MiTA PDF路径>`、`npm run test:pdf-links`、`npm run test:regression`。高亮专项使用真实 PDF 的前三页，覆盖字宽保留、字体与分栏边界、唯一引文定位、字符偏移、矩形去重及缩放归一化。DOM 选区、实际颜色和本地插件更新另由真实界面验收。

类型检查与构建通过；高亮专项通过 26 项、链接专项通过 308 项、既有回归通过 67 项。界面验收中发现仅恢复字宽仍有约 11% 偏差，进一步统一文字层与测量画布的语言后，原问题首行宽度从约 482px 回到 433px，第三行停在斜体 N 后。

真实界面验收 3/3 通过：旧记录在 51%、100%、156% 下对齐；新建跨行和段落中间选区保存后，在 80%、125% 及刷新后保持位置正确。本地插件已通过界面刷新到 0.4.5，仅做临时选择，不保存测试批注。真实论文的 PDF、笔记与批注文件哈希均未变化。私有证据与中文报告保存在本地验收目录，不随源码提交。

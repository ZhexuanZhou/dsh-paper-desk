# 知页 · 论文助手 1.0.0

知页将论文导入、PDF 阅读、AI 讨论、笔记卡片和研究专题放在一个工作台。论文库仍是用户自己选择的目录，保留普通 PDF、Markdown 与 JSON 文件。

## 主要能力

- 统一“导入论文”入口：本地多份 PDF、拖放、arXiv 页面或编号、公开 PDF 直链；使用当前配置的模型补全空的摘要、关键词和标签。
- 在 PDF 旁讨论论文，按需附上原页图片，核对回答引用的页码，复制原始 Markdown 和公式。
- 通过对话编辑、重写和重组笔记卡片；修改前保留历史，可预览、恢复和撤销恢复。
- 围绕研究问题关联多篇论文，使用 arXiv 或 OpenAlex 发现新文献，并保存关键词订阅。
- 使用目录和全文阅读笔记卡片；在阅读器中保留上次打开的论文。

## 1.0 的界面整理

- AI 助读改为左右对话布局：用户消息在右侧，以中性浅底气泡显示；AI 回答在左侧，保留长文阅读空间。气泡随内容收缩，宽屏最多占88%，窄面板最多占94%。
- 问题与回答统一为16px正文和1.85行高，问题不再显示成较小的引用文字。
- 每轮回答只显示一次 AI 助读标识；同轮思考和工具汇总到一个可展开的过程入口，回答原文保持次序。用户气泡只放正文，不再占一行显示角色名。
- 每轮提供一次复制，按双换行连接该轮各条 AI 回答的原始 Markdown，不含角色文字、工具过程或渲染后的公式。显式批注仍按原回答行定位。
- 用户问题默认完整显示。实际排版超过八行时提供手动收起，收起后显示四行；调整宽度或字号后重新计算，问题不再需要折叠时恢复全文。
- 实时消息和已保存对话使用同一组组件。模型调用、笔记卡片操作和对话数据保持原有行为。
- 合并顶部两个导入按钮为“导入论文”。统一弹窗提供本地 PDF 和论文链接两种方式，支持多选/拖放、键盘切换、链接回车提交、错误后保留输入和重试。
- 导入时显示实际状态，可关闭窗口在后台继续；进行中禁用重复提交。沿用既有上传、链接解析和元数据补全流程，不新增 DOI 下载能力。

- 回答选段编辑后用单一“完成”保存评论并带入底部正常输入框，保留原有草稿，可继续编辑后自行发送。移除单独的“统一提问”、重复确认和选段区直接发送入口，完成编辑本身不调用模型。重新编辑已保存评论时，更新草稿中未被手动改写的对应引用，避免重复追加。
- PDF选段浮层合并“提问”和“加入AI对话”为“加入提问”，先将引用和页码放进正常输入框，再由用户补充后发送。
- 左侧论文库统一为纵向列表，不再显示拥挤的多列表格或视图切换。排序改用共享菜单样式，保留添加时间、更新时间、标题和年份排序。

- 产品显示名称更新为“知页 · 论文助手”，英文界面为 Paper Companion。安装包、插件标识、存储目录与工具名称保持兼容，不迁移已有论文库。

- 统一普通弹窗、论文对比和关系图谱的基础背景及主题色；增大常用小按钮、关闭按钮和卡片操作区。深色模式下提高选中标签文字的亮度，主按钮使用独立底色。
- 补齐弹窗内的 Tab/Shift+Tab 焦点循环、关闭后的焦点恢复与顶层 Esc 行为。背景 PDF 和阅读器快捷键不再抢占其他弹窗的按键。
- 阅读器、对比和图谱标签页支持左右方向键及 Home/End，Tab 仅进入当前选中标签。
- 侧栏分隔条按下时保持宽度，拖动后保留最终位置；移动布局不继承桌面宽度。展开和收起使用分隔条中的箭头，箭头以外区域用于调整宽度；分隔条独立于滚动条，不再遮住滚动条。窄屏改用顶部“论文列表”开关。
- 编辑卡片中的删除会先显示确认；取消保留编辑草稿，确认仍校验原卡片版本，成功后才关闭编辑器。

## 安装与兼容

产品显示名称为“知页 · 论文助手”，英文为 Paper Companion。技术包名、插件标识、工具名称和存储结构继续兼容原有安装，不迁移或重写已有论文库。

GitHub Release 提供预构建安装包和 SHA-256 校验文件。Git tag、GitHub Release 与 npm 是独立渠道，请按各渠道实际版本安装。

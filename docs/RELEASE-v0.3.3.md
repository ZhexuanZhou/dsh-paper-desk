# PaperDesk v0.3.3

AI 助读的「对话失效」恢复。

## 问题

桌面版里，如果某篇论文缓存的 AI 会话已经失效/归档（或服务端换了实例），面板还能显示旧回答，
但继续提问会**被接受却不产生任何回复**：输入框清空、没有「正在思考…」、也没有报错。
用户只能看到“没反应”。

## 修复

- AI 助读抽屉新增 **「新会话」** 按钮：清掉这篇论文缓存的会话 id，重新创建一个干净的 AI 会话。
  （旧会话仍保留在左侧会话列表里，不会被删除。）
- 发送后如果 12 秒内既没有回复、也没有进入运行状态，面板会提示
  **「没有收到 AI 的回应。这个对话可能已经失效，可以新开一个会话。」**，并给出「新会话」按钮，
  不再静默失败。
- 说明：桌面版更新客户端后需要**重启应用**（仅刷新页面可能仍用旧缓存）。

## 安装

```sh
dsh plugin --profile web add @zhe_xuan/dsh-paper-desk
```

## 验证

- 点击「新会话」→ 对话清空并提示「已开始新的 AI 对话」→ 重新提问正常回复
- 桌面版实测：同一台机器、`dsh-app://` 客户端里上述流程通过

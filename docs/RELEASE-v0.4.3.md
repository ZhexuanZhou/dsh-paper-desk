# v0.4.3

- 品牌旁常驻显示从 package.json 注入的界面构建版本，便于确认当前界面是否已更新。悬停提示同时如实列出界面与后台报告的版本，不用可能缓存的后台版本给新界面标号。
- 移除 PDF 侧栏里的重复“笔记”入口。笔记仅从主标签进入整页阅读；旧侧栏笔记偏好回退为 AI 助读，不产生失效面板。
- 卡片页增加左侧目录，按卡片标题定位完整正文。当前阅读位置同步高亮，最后一张较短时也能正确选中；保留全文阅读与既有卡片操作。窄屏下目录改为横向滚动，不压缩正文。

本次不改变论文、笔记、卡片或订阅数据。验证路径为类型检查、构建及真实界面中检查版本、唯一笔记入口、目录跳转/滚动与空卡片状态。检索与正文排版沿用 v0.4.2 已通过的验收证据。

# 知页 · 论文助手 1.3.0

新增「论文复现」：把论文方法整理成可阅读、可编辑、可交给其他 Agent 执行的说明。

## 论文复现

- 在论文阅读器打开“论文复现”，可先补充算力、数据或实现范围，再生成说明。重新打开只读取已保存结果，不重复调用模型。
- 主区展示方法到代码的对应关系、数据与环境、实现顺序、验证方法、缺失信息和假设；目录与来源按需展开，右侧继续解释、评论和调整。
- 对话修改会实际更新同一份复现说明，成功后显示回执。手动编辑自动保存；修改前保留版本，可预览、恢复并撤销恢复。
- “复制给 Agent”导出独立的原始 Markdown 任务，包含论文来源、本次要求、完整说明、PDF中提供的相关链接及执行验收要求，保留公式与代码。背景链接明确标注未经联网核验。
- 论文来源改变后保留旧说明并提示更新。取消、失败或版本冲突不会覆盖已有文档，未保存草稿会保留并提示。
- 复现说明独立保存，不以笔记或卡片代替。需要写入笔记或卡片时，须在对话中明确要求。

## 结果与验证

“说明已生成”不代表代码已运行或实验成功。公式、伪代码和建议阈值需要结合原文与测试复核。此版本负责生成、编辑和交接说明，不会自动启动训练。可以在右侧粘贴外部运行记录，讨论实现差异；回传日志仍是待核对的资料。

数值验收区分原文指标与建议阈值，要求处理绝对/相对容差、零值和退化输入，并将确定性结果比较与性能计时分开。返回参数与指标应来自同一状态；未收敛或资源不足须标明未完成，不能算达到目标。合成数据或小规模验证不能替代论文指标复现。

## 阅读与编辑修正

- 修复表格中代码和公式的竖线被误当成分列符的问题。列数异常的行显示完整原行，不再丢弃后半段；保存与复制的原文保持不变。
- 原生 MathML 公式评论保留完整 TeX，不再把分数简单展平，也不重复展示同一个公式。
- 切换前询问保存或放弃时暂停复现说明自动保存，放弃操作不会被后台保存覆盖；真实并发修改仍会被保护。
- 修复旧元数据缺少时间戳时可能出现的伪并发冲突。

## 安装与数据

下载 `dsh-paper-desk-1.3.0.tgz` 并按 `SHA256SUMS` 校验。源码链接安装需构建并刷新界面；若重新开关插件后后台仍保留旧行为，请先保存工作，再完整退出并重新打开 Harness，核对新功能是否实际生效。

说明位于 `<库>/papers/<论文ID>/reproduction.json`，历史位于 `<库>/.paperdesk/history/<论文ID>/reproduction/`。编辑与讨论草稿保存在当前浏览器，按论文库和论文区分，不作为跨设备同步的已保存文档。浏览器存储失败时会提示。

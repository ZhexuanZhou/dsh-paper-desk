# 1.1.1 — 专题阅读、评论与讨论

研究专题以主报告为中心。初始解读独立执行，右侧用于继续提问和编辑文档；修复初始解读与讨论复用空会话、导致报告左右重复的问题。已有会话中的初始解读记录折叠保留，可展开查看原始内容。

## 使用变化

- 拖动两侧分隔线调整专题列表、讨论宽度，箭头原位收起或展开。记住宽度和展开状态，支持键盘调整、双击复位和 Escape 取消拖动；窄窗口使用覆盖面板。
- 主报告限制阅读行宽，提供分节目录、原始 Markdown 复制和重新生成入口，保持低饱和配色。
- 选中文字后主动点击“添加评论”，编辑并完成后加入普通输入框的附件。可积累、修改和移除多条评论，再随问题一次发送。划词不会自动弹出编辑区或调用模型。
- 评论保留原文、分节、版本与相关 TeX 公式；旧版本引用明确标记。未发送的问题、评论和未完成编辑按专题保存在当前浏览器。
- Agent 实际修改解读、专题笔记或卡片后，聊天显示保存回执和改动摘要。完整原回复可展开、复制；失败操作不能显示成成功保存。
- 导入弹窗使用稳定外框和固定底部状态区，结果在内部滚动；为加载与重试操作预留宽度，避免进度、结果和错误提示出现时反复移动窗口。

## 数据与边界

普通讨论和添加评论保持只读；明确要求修改才写入文档，并沿用原有版本恢复能力。评论草稿不写入论文库，不跨设备同步。浏览器存储不可用时提供提示及当前页面内的临时恢复，关闭页面后不承诺保留。

单条问题、引用和评论各最多 4000 字符，问题及评论的 JSON 总计最多 16000 字符；已有资料总预算仍为 60000 字符。超出时提示缩短或分次发送，不静默截断。屏幕上的公式、模型建议和引用页码仍需要核对原论文。

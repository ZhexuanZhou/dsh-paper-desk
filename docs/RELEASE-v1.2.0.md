# 知页 · 论文助手 1.2.0

文献发现支持自然语言需求。输入“小语种翻译”并补充研究背景，Agent 会扩展检索词、联网查找并解释相关论文，不再要求用户掌握检索网站的语法。

## 主要变化

- 重做文献发现输入区：多行输入、示例需求、键盘提交、进度和停止操作，沿用低饱和配色。
- 使用 Harness 的 `web_search` 与 `web_fetch` 能力；不增加厂商绑定，也不更改用户现有的搜索配置。
- 区分 Agent 的解释和搜索工具实际返回的来源。联网缺失、失败或没有可核验来源时明确提示。
- 本机保留检索历史与输入草稿，不按条数自动清理，用户可逐条删除或清空，切换页面后可继续查看；不同论文库分开保存。浏览器存储失败会提示。
- 发现过程只读，不自动导入论文。链接批量导入全部成功后自动关闭弹窗，有失败项则保留结果以便重试。PDF/arXiv 来源可手动导入；普通网页先打开原页取得 PDF。
- 原 arXiv、OpenAlex 检索与订阅收进“高级检索与订阅”，既有订阅保持兼容。

## 元数据自动保存

- 信息页手动编辑与自动补全结果均直接保存，不再要求额外点击保存按钮。
- 保存期间的新输入不会被旧响应覆盖；失败时保留草稿并提供重试。
- 可撤销、重做最近一次匹配修改。前后版本保存在论文库中，仅恢复可编辑字段，保留 PDF 身份和存储信息。
- 检测到字段或版本冲突时停止覆盖，避免撤销后续修改。

## 使用要求

请先在 Harness 配置可用的模型与联网检索。研究需求及扩展查询会发送至模型和当前配置的搜索服务。网页和模型返回内容仍需核对原文；检索不保证覆盖全部论文。

## 安装

下载 `dsh-paper-desk-1.2.0.tgz`，按 `SHA256SUMS` 校验后安装。本地源码安装需重新构建，并在插件管理器中关闭再开启插件；打开的页面需刷新。

## 导入与阅读交互修正

- 修复结果列表边缘加载图标旋转导致的横向溢出，避免滚动条反复出现。
- 链接批量导入全部成功后自动关闭窗口并打开论文；仍有失败或待处理条目时保留结果，支持重试。
- 元数据补全说明移到可展开的数据说明中，不再在完成状态下显示成待处理提示。
- PDF 可视选择增加起点与当前端点标记，跟随缩放和滚动。Shift+h/j/k/l 移动光标重新定位，h/j/k/l 扩展选区。上下移动按实际文字位置寻找相邻行，并保持横向位置。
- 阅读状态移到标题旁，改用低饱和的圆角状态标签：未读为蓝灰、在读为绿色、已读为青灰，去除箭头；展开菜单沿用相同颜色与页面底色。论文标签在作者下方靠左排列，点击“+N”展开全部。
- 联网检索的“开始”和“停止”使用独立控件，避免完成瞬间误触发新检索。
- 移除顶部重复的论文列表按钮，窄窗口保留侧边箭头。
- 修正远距离跳页时绘制与页码提交的顺序；尺寸稳定后确保当前页绘制，窄窗口保持阅读器完整高度，避免恢复阅读后空白。

# 知页 · 论文助手 1.3.1

统一复现区的颜色和留白，并让文献发现的检索记录更容易识别。

## 颜色与排版

- 复现区与外层页面共用暖灰背景，去掉整块纯白面板的包围边界；固定工具栏使用相同底色。
- 空状态去掉装饰图标、重复口号及介绍，保留单个标题、简短说明、可选要求与生成按钮；与工具栏标题对齐，减少上下留白。输入框保留较亮底色、细边框和焦点提示。
- 已读标签、状态菜单和列表圆点使用同一灰绿色；状态文字继续明确显示未读、在读、已读和已归档。
- 文献发现输入区改为紧凑的两行起始高度，保留多行输入、手动调整高度和原有提交快捷键。

## 检索记录标题

- 新检索在同一次 Agent 任务中根据实际结果生成简短主题标题，无额外标题模型请求。
- 左侧记录和结果区使用该标题；完整问题可通过“查看原始问题”展开，原始回答保持不变。
- 旧记录优先提取已有解读的主题标题，其次采用已有结果来源的标题；没有可用结果时保留问题摘要。历史记录不会自动重跑或被清理。
- 无实际成功联网检索的回答仍显示错误或未核验状态，不因有标题而算作检索成功。

## 安装

下载 `dsh-paper-desk-1.3.1.tgz` 并按 `SHA256SUMS` 校验。源码链接安装请先构建并刷新插件页面；若重开插件后仍是旧界面，先保存工作，再完整退出并重新打开 Harness，核对新界面是否生效。

此版没有改变论文复现、笔记和卡片的数据格式。生成的研究内容仍需结合原文与测试复核。

本版后台代码与 1.3.0 相同。已有宿主进程可能缓存旧的后台包版本信息；本地界面已加载 1.3.1 时，可以使用本轮界面与检索标题改动，无需仅为版本信息反复重启。

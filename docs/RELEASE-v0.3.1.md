# PaperDesk v0.3.1

阅读器 AI 面板的一次小修与整理。

## 修复

- **发送不再“无声失败”**：以前点击「发送」会先清空输入框；如果会话拒绝/失败，问题文本就消失了。
  现在只有在会话接受后才清空，失败时保留问题并显示错误提示，方便重试。
- **发送即时反馈**：等待连接/提交期间就显示「正在思考…」，不用等首字出来才知道有没有点中。
- 输入为空时发送按钮保持禁用，不再出现“点了没反应”。

## 界面整理

- 去掉阅读器右上角重复的「AI 解读」按钮；现在只有一个入口：标题栏下方的 **「AI 助读」** +
  总结 / 方法精读 / 审阅 / 相关工作 / 提问。
- 抽屉里重复的一套任务按钮已移除；抽屉只保留对话、引用页、生成卡片和输入框。
- 统一命名：原来的「AI 解读」和「Agent 精读」现在都叫 **「AI 助读」**（英文 AI reading）。

## 安装

```sh
dsh plugin --profile web add @zhe_xuan/dsh-paper-desk
```

或使用本 Release 的预构建包（内容与 npm 一致）。

## 验证

- 点击「AI 助读」打开抽屉 → 直接提问 → 回复正常出现，输入框在成功后清空
- 顶部不再有重复的 AI 按钮；抽屉内不再有第二套任务栏
- 中文/英文文案同步更新，`tsc` 与构建通过
